```mermaid
    C -->|30-70| REVIEW[⚠️ REVIEW<br/>Extra check]
    C -->|70-100| BLOCK[🚫 BLOCK]
```

**Decision**:
- **Safe (0-30%)**: Process instantly.
- **Review (30-70%)**: Ask OTP/biometric.
- **Block (>70%)**: Stop + alert.
